## 🎯 Goals / Objectives

* Understand the role of the `<p>` element in organizing text within a page.  
* Learn how to use the `<b>` element to highlight or emphasize words.  

---

## 📝 Summary & Core Concepts

In HTML, the paragraph element is essential for structuring text. Without it, any long text will appear as one continuous line, making it difficult to read.  
The `<p>` element tells the browser to start a new paragraph, ensuring text is displayed neatly.  

The `<b>` element is used to format text and make it **bold**, helping draw attention to specific words.  

### 📑 Key Concepts
* **Paragraph `<p>`:** Used to divide text into clear, readable sections.  
* **Bold `<b>`:** Used to make text thicker and more noticeable.  

---

## ⚙️ Practical Commands & Examples

### 1. Using Paragraphs

**Description:** Writing multiple lines of text using `<p>`.

```html
<p>This is the first paragraph.</p>
<p>This is the second paragraph.</p>
<p>This is the third paragraph.</p>
```

---

### 2. Using Bold Formatting

**Description:** Highlighting a word or phrase with `<b>`.

```html
<p>Welcome to the <b>Book Store</b> website!</p>
```

**Result:** The words "Book Store" will appear in bold compared to the rest of the text.
