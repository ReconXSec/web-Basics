## 📝 Summary & Core Concepts

HTML provides multiple text elements that help structure content and add meaning or special formatting:  

- **`q`**: An *inline* element used for short quotations within text.  
- **`blockquote`**: A *block* element used for longer quotes or sayings, adding automatic margins.  
- **`button`**: An element to create a clickable button, often used with JavaScript or forms.  
- **`wbr`**: An element that allows the browser to break long text (like URLs) when needed to avoid layout issues.  
- **`bdi`**: An element that isolates text in different languages to prevent direction conflicts.  

### 📑 Key Concepts
* **Inline vs Block:** Difference between elements that appear within a line (inline) and those that take full width (block).  
* **Text Control:** Elements like `wbr` and `bdi` help manage text display more effectively.

## ⚙️ Practical Commands & Examples

### 1. Short Quote (q)
```html
<p>He said: <q>I watch the TV, I am the ghost of cybersecurity</q></p>
```

---

### 2. Long Quote (blockquote)
```html
<blockquote>
    "I watch the TV, I am the ghost of cybersecurity"
</blockquote>
```

---

### 3. Button
```html
<button>Click Me</button>
```

---

### 4. Breaking Long Text (wbr)
```html
<p>https://www.youtube.com/watch?<wbr>v=6QAELgirvjs&list=PLDoPjvoNmBAw_t_XWUFbBX-c9MafPk9ji</p>
```

---

### 5. Isolating Multilingual Text (bdi)
```html
<p><bdi>السلام</bdi> 2 welcome</p>
```
