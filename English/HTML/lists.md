## 🎯 Goals / Objectives

---

## 📝 Summary & Core Concepts

In HTML, there are three main types of lists:  

- **`ul`**: Unordered list (bulleted).  
- **`ol`**: Ordered list (numbered or lettered).  
- **`dl`**: Description list that pairs items with their descriptions.  

### 📑 Key Concepts
* **UL:** Unordered bulleted list.  
* **OL:** Ordered numbered list with extra options like `reversed`, `start`, and `type`.  
* **DL:** Description list linking items with their definitions.  

---

## ⚙️ Practical Commands & Examples

### 1. Unordered List (ul)
```html
<ul>
    <li>CSS</li>
    <li>CS</li>
</ul>
```
**Result:**
- CSS  
- CS  

---

### 2. Ordered List (ol)
```html
<ol>
    <li>Name</li>
    <li>Age</li>
    <li>Wallet</li>
</ol>
```
**Result:**
1. Name  
2. Age  
3. Wallet  

#### Extra Options:
- **reversed**: Reverses the order.
```html
<ol reversed>
    <li>Fgg</li>
    <li>Ssd</li>
    <li>Dof</li>
</ol>
```

- **start**: Starts numbering from a specific value.
```html
<ol start="100">
    <li>Fgg</li>
    <li>Ssd</li>
    <li>Dof</li>
</ol>
```

- **type**: Defines numbering style (numbers, uppercase letters, lowercase letters, Roman numerals).
```html
<ol type="I">
    <li>Fgg</li>
    <li>Ssd</li>
    <li>Dof</li>
</ol>
```

---

### 3. Description List (dl)
```html
<dl>
    <dt>HTML</dt>
    <dd>That is a language for web and computer</dd>
</dl>
```
- **dl**: Description list.  
- **dt**: Term to be described.  
- **dd**: Description of the term.
