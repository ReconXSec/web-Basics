
# 📚 HTML Text Elements (SPAN, BR, HR, Strong)

**Date:** December 24, 2025  
**Level:** Beginner  
**Status:** 🟢 Completed  

---

## 🎯 Goals / Objectives

* Learn the basic text elements: `span`, `br`, `hr`, and `strong`.  
* Understand how to use them to format text and paragraphs in HTML pages.  
* Distinguish between elements that add semantic meaning and those that only provide visual formatting.  

---

## 📝 Summary & Core Concepts

- **`span`**: An *inline* element used to customize text and paragraphs with CSS. It has no default styling but allows full control over appearance.  
- **`br`**: An element used to insert a line break within a paragraph.  
- **`hr`**: An element used to draw a horizontal line separating paragraphs or sections.  
- **`strong`**: An element used to make text bold while also adding semantic meaning that the text is important.  

### 📑 Key Concepts
* **Span:** A tool for applying CSS styles to specific text.  
* **BR:** Breaks a line inside a paragraph.  
* **HR:** Creates a horizontal divider between sections.  
* **Strong:** Bold text with semantic emphasis.  

---

## ⚙️ Practical Commands & Examples

### 1. Using `span`
```html
<p>This is a <span style="color:blue;">blue word</span> in a sentence.</p>
```

---

### 2. Using `br`
```html
<p>First line<br>Second line<br>Third line</p>
```

---

### 3. Using `hr`
```html
<p>Introduction</p>
<hr>
<p>Details go here...</p>
```

---

### 4. Using `strong`
```html
<p>Hello <strong>Bilal</strong>, welcome to HTML basics!</p>
```

---

## 📊 Outcomes & Key Takeaways

* **Positive Outcome:** Learned how to use simple but essential elements to organize and format text.  
* **Challenge Faced:** Differentiating between semantic elements like `strong` and purely visual ones like `span`.  
* **Key Lesson:** Use `span` with CSS for customization, `strong` to highlight important text, and `br`/`hr` for visual organization of paragraphs.
