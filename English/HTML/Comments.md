## 📝 Summary & Core Concepts

Comments are text written inside the code but not displayed to the user in the browser.  
Their purpose is to explain the code to other developers or to yourself when reviewing the project later.  
They are used in almost all programming languages, and in HTML they are written between `<!--` and `-->`.

### 📑 Key Concepts
* **Comment:** Non-executable text meant for clarification only.  
* **Single-line comment:** A short comment for one line.  
* **Multi-line comment:** A longer comment spanning multiple lines.  
* **Best Practices:** Comments should be clear and useful, not repetitive or unnecessary.  

---

## ⚙️ Practical Commands & Examples

### 1. Single-line Comment
```html
<!-- This is a single-line comment -->
<p>Welcome to my website!</p>
```

---

### 2. Multi-line Comment
```html
<!--
This is an example of a multi-line comment
You can write a longer explanation here
to clarify the purpose of the code
-->
<p>Hello World!</p>
```

---

### 3. Using Comments to Clarify Sections
```html
<!-- Header Section -->
<header>
    <h1>My Website</h1>
</header>

<!-- Content Section -->
<main>
    <p>This is the main content.</p>
</main>
```

---

## ⚠️ Common Mistakes

* Forgetting to close the comment with `-->`, which can break the code.  
* Using comments to hide entire blocks of code instead of organizing them properly.  
* Writing unhelpful comments like `<!-- Start of code -->` without real explanation.
