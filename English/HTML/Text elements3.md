## 🎯 Goals / Objectives

* Learn about the `code` and `pre` elements in HTML.  
* Understand how to display programming code inside a page while preserving formatting and spacing.  

---

## 📝 Summary & Core Concepts

- **`code`**: An element used to display programming code within a page. It indicates that the text is code rather than normal text.  
- **`pre`**: An element used to preserve spacing and formatting exactly as written in the editor. Any indentation or line breaks will be displayed as they are.  

When combined, these elements allow code to be shown in a clear and organized way, maintaining its original formatting.

### 📑 Key Concepts
* **code:** Defines text as programming code.  
* **pre:** Preserves spacing and original formatting of text.  

---

## ⚙️ Practical Commands & Examples

### 1. Example of Using `code` and `pre`

```html
<code>
    <pre>
        x = input("Choose a number:")
    </pre>
</code>
```

**Explanation:**  
- The `<code>` element indicates that the text is code.  
- The `<pre>` element ensures that indentation and formatting are preserved as written in the editor.

* **Positive Outcome:** Successfully displayed code inside a page in a clear and organized way.  
* **Challenge Faced:** Understanding the difference between displaying normal text and displaying code with preserved formatting.
