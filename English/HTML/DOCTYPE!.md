## 🎯 Goals / Objectives

---

## 📝 Summary & Core Concepts

The **Doctype** is not an HTML element. It is an instruction that tells the browser **which version of HTML** the page is using.  
It is very important because it ensures the browser displays the page according to web standards and prevents compatibility problems.  

### 📑 Key Concepts
* **Doctype:** A declaration that specifies the HTML version used.  
* **Standards Mode:** The mode in which browsers follow web standards when a valid Doctype is present.  

---

## ⚙️ Practical Commands & Examples

### 1. Writing Doctype at the Beginning of a Page

**Description:** It must be the very first line in any HTML file.

```html
<!DOCTYPE html>
<html>
<head>
    <title>Example Page</title>
</head>
<body>
    <h1>Hello World</h1>
</body>
</html>
```
