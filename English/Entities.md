## 📝 Summary & Core Concepts

In HTML, if you write `<p>` directly inside a page, the browser interprets it as an HTML element rather than plain text.  
To solve this, we use **entities**, which are special codes written differently but displayed as normal text.  

### 📑 Key Concepts
* **Entity:** A special code used to display reserved characters in HTML as plain text.  
* **&lt;**: Represents the "less than" symbol `<`.  
* **&gt;**: Represents the "greater than" symbol `>`.  

---

## ⚙️ Practical Commands & Examples

### 1. Writing an HTML element as plain text
```html
&lt;p&gt;
```
**Result:** Displays `<p>` as plain text instead of being interpreted as an HTML tag.  

---

### 2. Examples of common entities
```html
&lt;div&gt;   <!-- Displays <div> as text -->
&lt;h1&gt;    <!-- Displays <h1> as text -->
&lt;a&gt;     <!-- Displays <a> as text -->
```

---

### 3. Using entities inside text
```html
<p>To write HTML tags like &lt;p&gt; or &lt;div&gt; as plain text, use entities.</p>
```
