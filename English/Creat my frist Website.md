## 📝 Summary & Core Concepts

Every HTML page must start with the `<html>` element, which represents the beginning and end of the page.  
Inside the page, there are two essential sections:  

1. **`head`**: Contains page information such as the title and metadata.  
2. **`body`**: Contains everything visible to the user, such as text, links, and images.  

The **`title`** element is written inside the `head` and defines the page name that appears at the top of the browser.

### 📑 Key Concepts
* **html:** The root element that contains all page elements.  
* **head:** Section for page information (metadata).  
* **body:** Section that displays content to the user.  
* **title:** Defines the page title shown in the browser tab.  

---

## ⚙️ Practical Commands & Examples

### 1. Example of a Simple HTML Page

```html
<html>
    <head>
        <title>civora</title>
    </head>
    <body>
        Welcome to arena, welcome the great Bilal!
    </body>
</html>
```

**Explanation:**  
- The code starts and ends with the `<html>` element.  
- The `<head>` element contains `<title>`, which sets the page title (civora).  
- The `<body>` element contains the text visible to the user.
