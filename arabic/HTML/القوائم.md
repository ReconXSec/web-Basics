
# 📚 القوائم في HTML (Lists)

---

## 🎯 الأهداف (Goals / Objectives)

* التعرف على الأنواع المختلفة للقوائم في HTML: `ul`, `ol`, و `dl`.  
* فهم كيفية استخدام الخصائص مثل `reversed`, `start`, و `type` مع القوائم المرتبة.  
* معرفة دور القوائم الوصفية في تنظيم المعلومات.  

---

## 📝 الملخص والمفاهيم الأساسية (Summary & Core Concepts)

في HTML توجد ثلاثة أنواع رئيسية من القوائم:  

- **`ul`**: قائمة غير مرتبة (نقطية).  
- **`ol`**: قائمة مرتبة (مرقمة أو بالحروف).  
- **`dl`**: قائمة وصفية تربط العنصر بوصفه.  

### 📑 مفاهيم رئيسية
* **UL:** قائمة نقطية غير مرتبة.  
* **OL:** قائمة مرقمة مرتبة مع خيارات إضافية مثل `reversed`, `start`, و `type`.  
* **DL:** قائمة وصفية تربط العناصر بتعريفاتها.  

---

## ⚙️ الأوامر والتطبيق العملي (Practical Commands & Examples)

### 1. قائمة غير مرتبة (ul)
```html
<ul>
    <li>CSS</li>
    <li>CS</li>
</ul>
```
**النتيجة:**
- CSS  
- CS  

---

### 2. قائمة مرتبة (ol)
```html
<ol>
    <li>Name</li>
    <li>Age</li>
    <li>Wallet</li>
</ol>
```
**النتيجة:**
1. Name  
2. Age  
3. Wallet  

#### خيارات إضافية:
- **reversed**: يعكس الترتيب.
```html
<ol reversed>
    <li>Fgg</li>
    <li>Ssd</li>
    <li>Dof</li>
</ol>
```

- **start**: يبدأ العد من رقم معين.
```html
<ol start="100">
    <li>Fgg</li>
    <li>Ssd</li>
    <li>Dof</li>
</ol>
```

- **type**: يحدد نمط الترقيم (أرقام، حروف كبيرة، حروف صغيرة...).
```html
<ol type="I">
    <li>Fgg</li>
    <li>Ssd</li>
    <li>Dof</li>
</ol>
```

---

### 3. قائمة وصفية (dl)
```html
<dl>
    <dt>HTML</dt>
    <dd>That is a language for web and computer</dd>
</dl>
```
- **dl**: قائمة وصفية.  
- **dt**: العنصر المراد وصفه.  
- **dd**: الوصف الخاص بالعنصر.

## 📊 النتائج والدروس المستفادة (Outcomes & Key Takeaways)

* **النتيجة الإيجابية:** تعلمت كيفية إنشاء القوائم بأنواعها المختلفة وتنظيم المعلومات بشكل مرتب.  
* **التحدي الذي واجهني:** التمييز بين القوائم المرتبة وغير المرتبة واستخدام الخصائص الإضافية بشكل صحيح.  
* **درس أساسي:** استخدم `ul` للقوائم البسيطة، `ol` للقوائم المرتبة مع خيارات إضافية، و `dl` لتعريف العناصر بوصفها.
