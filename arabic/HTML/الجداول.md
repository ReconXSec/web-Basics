
# 📚 الجداول في HTML (Tables)

**التاريخ:** 4 يناير 2026  
**المستوى:** مبتدئ  
**الحالة:** 🟢 مكتمل  

---

## 🎯 الأهداف (Goals / Objectives)

* فهم كيفية إنشاء الجداول باستخدام الوسم `<table>`.  
* التعرف على العناصر الأساسية للجداول: `thead`, `tbody`, `tfoot`.  
* معرفة دور الوسوم الإضافية مثل `th`, `caption`, و `colspan`.  
* إدراك كيفية تنظيم البيانات داخل الجدول بشكل مرتب وواضح.  

---

## 📝 الملخص والمفاهيم الأساسية (Summary & Core Concepts)

الجداول في HTML تُستخدم لعرض البيانات بشكل منظم في صفوف وأعمدة.  
رغم أن تصميم الجداول يُفضل باستخدام CSS لاحقًا، إلا أن HTML يوفر وسوم أساسية لبناء الهيكل:  

- **`<table>`**: بداية الجدول.  
- **`<thead>`**: الجزء العلوي (عناوين الأعمدة).  
- **`<tbody>`**: البيانات الفعلية داخل الجدول.  
- **`<tfoot>`**: الجزء السفلي (ملخص أو نتائج).  
- **`<tr>`**: صف داخل الجدول.  
- **`<td>`**: خلية بيانات.  
- **`<th>`**: خلية عنوان مميزة بخط غامق.  
- **`<caption>`**: عنوان الجدول.  
- **`colspan`**: دمج عدة خلايا في خلية واحدة.

## ⚙️ الأوامر والتطبيق العملي (Practical Commands & Examples)

### 1. جدول بسيط
```html
<table>
  <thead>
    <tr>
      <th>Age</th>
      <th>Job</th>
      <th>Name</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>40</td>
      <td>Engineer</td>
      <td>Oussama</td>
    </tr>
  </tbody>
</table>
```
**النتيجة:** جدول يحتوي على صف واحد مع عناوين أعمدة.  

---

### 2. استخدام `tfoot` لعرض ملخص
```html
<table>
  <thead>
    <tr>
      <th>Product</th>
      <th>Price</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>Book</td>
      <td>10$</td>
    </tr>
    <tr>
      <td>Pen</td>
      <td>2$</td>
    </tr>
  </tbody>
  <tfoot>
    <tr>
      <td>Total</td>
      <td>12$</td>
    </tr>
  </tfoot>
</table>
```
**النتيجة:** يظهر ملخص في أسفل الجدول.  

---

### 3. إضافة عنوان للجدول باستخدام `caption`
```html
<table>
  <caption>Student List</caption>
  <thead>
    <tr>
      <th>Name</th>
      <th>Grade</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>Bilal</td>
      <td>A+</td>
    </tr>
  </tbody>
</table>
```
**النتيجة:** يظهر عنوان "Student List" فوق الجدول.  

---

### 4. دمج خلايا باستخدام `colspan`
```html
<table>
  <thead>
    <tr>
      <th>Name</th>
      <th colspan="2">Details</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>Oussama</td>
      <td>Age: 40</td>
      <td>Job: Engineer</td>
    </tr>
  </tbody>
</table>
```
**النتيجة:** العمود الثاني يغطي مساحتين لعرض تفاصيل متعددة.  

---

### 5. مثال كامل يجمع كل العناصر
```html
<table>
  <caption>Employee Data</caption>
  <thead>
    <tr>
      <th>Name</th>
      <th>Department</th>
      <th>Salary</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>Bilal</td>
      <td>IT</td>
      <td>2000$</td>
    </tr>
    <tr>
      <td>Oussama</td>
      <td>HR</td>
      <td>1800$</td>
    </tr>
  </tbody>
  <tfoot>
    <tr>
      <td colspan="2">Average Salary</td>
      <td>1900$</td>
    </tr>
  </tfoot>
</table>
```
**النتيجة:** جدول متكامل يحتوي على عنوان، بيانات، وملخص.

## 📊 النتائج والدروس المستفادة (Outcomes & Key Takeaways)

* الجداول تنظم البيانات في صفوف وأعمدة.  
* `thead`, `tbody`, و `tfoot` تساعد في تقسيم الجدول إلى أجزاء واضحة.  
* `th` يميز العناوين بخط غامق.  
* `caption` يضيف عنوانًا للجدول.  
* `colspan` يسمح بدمج الخلايا لتوسيع العرض.  
* يُفضل لاحقًا استخدام CSS لتنسيق الجداول بشكل احترافي.
