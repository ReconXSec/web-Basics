
# 📚 عناصر نصية في HTML (SPAN, BR, HR, Strong)

**التاريخ:** 24 ديسمبر 2025  
**المستوى:** مبتدئ  
**الحالة:** 🟢 مكتمل  

---

## 🎯 الأهداف (Goals / Objectives)

* التعرف على العناصر النصية الأساسية: `span`, `br`, `hr`, و `strong`.  
* فهم كيفية استخدامها لتنسيق النصوص والفقرات داخل صفحات HTML.  
* معرفة الفرق بين العناصر التي تضيف معنى (semantic) والعناصر التي تضيف فقط تنسيقًا بصريًا.  

---

## 📝 الملخص والمفاهيم الأساسية (Summary & Core Concepts)

- **`span`**: عنصر *inline* يُستخدم لتخصيص النصوص والفقرات باستخدام CSS. لا يضيف أي تنسيق افتراضي لكنه يتيح التحكم الكامل بالمظهر.  
- **`br`**: عنصر يُستخدم لإضافة سطر جديد داخل الفقرة.  
- **`hr`**: عنصر يُستخدم لرسم خط أفقي يفصل بين الفقرات أو الأقسام.  
- **`strong`**: عنصر يُستخدم لجعل النص غامقًا (Bold) مع إضافة معنى دلالي بأن النص مهم.  

### 📑 مفاهيم رئيسية
* **Span:** أداة لتطبيق تنسيقات CSS على نصوص محددة.  
* **BR:** كسر السطر داخل الفقرة.  
* **HR:** خط فاصل بين الأقسام.  
* **Strong:** نص غامق مع دلالة على الأهمية.  

---

## ⚙️ الأوامر والتطبيق العملي (Practical Commands & Examples)

### 1. استخدام `span`
```html
<p>This is a <span style="color:blue;">blue word</span> in a sentence.</p>
```

---

### 2. استخدام `br`
```html
<p>First line<br>Second line<br>Third line</p>
```

---

### 3. استخدام `hr`
```html
<p>Introduction</p>
<hr>
<p>Details go here...</p>
```

---

### 4. استخدام `strong`
```html
<p>Hello <strong>Bilal</strong>, welcome to HTML basics!</p>
```

## 📊 النتائج والدروس المستفادة (Outcomes & Key Takeaways)

* **النتيجة الإيجابية:** تعلمت كيفية استخدام عناصر بسيطة لكنها أساسية لتنظيم وتنسيق النصوص.  
* **التحدي الذي واجهني:** التمييز بين العناصر التي تضيف معنى دلالي مثل `strong` والعناصر التي تضيف فقط تنسيق مثل `span`.  
* **درس أساسي:** استخدم `span` مع CSS للتخصيص، و `strong` لإبراز النصوص المهمة، بينما `br` و `hr` لتنظيم الفقرات بصريًا.
